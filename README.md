## 🚀 Cara Menjalankan

1. Pastikan sudah terinstall [Java JDK](https://www.oracle.com/java/technologies/downloads/).
2. Pilih folder praktikum yang diinginkan.
3. Jalankan file `.java` menggunakan perintah berikut di terminal:

	 ```powershell
	 javac NamaFile.java; java NamaFile
	 ```
